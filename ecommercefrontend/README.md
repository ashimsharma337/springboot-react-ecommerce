# Ecommerce Frontend

This TypeScript React application uses Vite.

## Development

From this directory, run:

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

Run the TypeScript check separately with:

```sh
npm run typecheck
```

## Production

```sh
npm run build
npm run preview
```

The production bundle is written to `dist/`.
